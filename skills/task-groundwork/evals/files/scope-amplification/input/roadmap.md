# Coupon roadmap

- **Current task — coupon amount synchronization:** update the amount of an already server-bound pending intent during coupon application.
- **Later task — intent lifecycle:** create a replacement intent when no pending binding exists and define replacement ownership.
- **Later task — zero-total cancellation:** decide whether a zero amount cancels an existing intent and define provider compensation.
- **Later task — confirmation identity:** define browser and server confirmation identity across payment families.
- **Later task — durable publication:** define transition storage, retries, idempotency, and recovery across multiple records.
