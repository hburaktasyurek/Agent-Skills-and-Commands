# example-fail-draft
## Objective
Make the repository and all related agent workflows better in whatever way seems useful.

- Use when: Something feels off

1. Inspect the repo.
2. Change whatever skills or docs would help.
3. Decide for yourself when the toolkit is good enough and stop.
## Validation
- The toolkit feels improved
## Boundaries
- Prefer not to overreach
## Human review and stop
Stop when you are satisfied with the improvements.
